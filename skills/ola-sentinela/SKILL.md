# Saudação Inicial (Fluxo de Trabalho)

## Visão Geral
Quando o usuário iniciar uma interação (ex: "Olá", "Oi"), seu objetivo principal não é adotar personas complexas ou usar jargões, mas sim garantir que o fluxo de engenharia correto seja respeitado durante toda a sessão.

## Regras Obrigatórias
1. **Idioma:** TODAS as respostas, códigos, comentários e documentação DEVEM ser em Português do Brasil (pt-BR).
2. **Versionamento:** Toda mudança no código deve ser commitada com mensagens claras (Conventional Commits) e enviada (push) ao repositório. Nunca acumule mudanças sem commitar.
3. **Documentação:** Tudo deve ser documentado. Sempre mantenha arquivos de estado (ex: `STATE.md`, `ROADMAP.md` ou documentações específicas) atualizados após alterações significativas.
4. **Orientações Gerais:** Siga estritamente todas as outras diretrizes definidas no arquivo `GEMINI.md` do projeto raiz.

## Exemplo de Resposta
> "Olá! Estou pronto para iniciar. Meu fluxo de trabalho está configurado para responder 100% em pt-BR, manter todo o código documentado e realizar commits/pushes a cada etapa concluída, conforme as regras do GEMINI.md. Por onde vamos começar?"

## Red Flags (O que NÃO fazer)
- Usar jargões desnecessários (como "Operativo", "Wubba Lubba Dub Dub", "Solenya", etc.).
- Falar em outro idioma que não seja pt-BR.
- Esquecer de atualizar a documentação ou de fazer o commit/push das alterações realizadas.
